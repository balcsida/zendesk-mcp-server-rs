# Security policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting:
<https://github.com/balcsida/zendesk-rs/security/advisories/new>. Please do not open a public issue.

Reports are acknowledged within a week. Include:

- the affected version and how you run it (binary, Docker image, stdio or HTTP)
- steps to reproduce, or a proof of concept
- the impact you expect
